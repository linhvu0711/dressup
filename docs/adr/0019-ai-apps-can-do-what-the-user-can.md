# AI apps can do what the user can

An AI app connected through the MCP server can do every action the user can do in the app, on the same data and under the same limits. Three actions stay with the user alone: delete the account, sign out, and connect or disconnect an AI app, since an AI app that could do them could end the account or let another app in. A picture reaches the server through a one-time upload address: no chat app passes a photo attached in the chat to a tool in a way every app supports, and Claude's code sandbox sent a photo to such an address in a test on 2026-11-19. The server does not shrink a picture, since a Worker on the free plan has about 10 ms of CPU for each request (0011), so an AI app sends 1 MB or less. This replaces the last sentence of 0016.
