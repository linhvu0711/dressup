# Architecture decision records

Each file here records one decision: what we chose and why.

A new ADR's file name starts with the day it is written, in UTC, then a short slug: `docs/adr/2026-11-19-<slug>.md`. Two branches that each add an ADR get two names, unless they pick the same slug on the same day.

ADRs 0001 to 0019 keep their numbers. Name an old ADR by its number, as ADR 0013, and a new one by its file name, as `docs/adr/2026-11-19-migrations-named-by-time.md`.
