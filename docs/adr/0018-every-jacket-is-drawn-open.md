# Every jacket is drawn open

A jacket has no open or closed state. Every place the app draws a jacket draws it open, so the inner top under it shows. A combination is its pieces alone: two combinations with the same pieces are one, and the app refuses the second. The owner said the state plays no role in a combination, which is about the colours that go together; an open jacket shows them all. This supersedes the part of 0014 that made the jacket state part of a combination's identity.
