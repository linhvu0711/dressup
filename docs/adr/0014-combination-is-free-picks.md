# A combination is free picks, one for each layer

A combination holds 2 to 4 pieces, at most one for each layer: bottom, inner top, sweater, jacket. Combinations do not use the 23 fixed modes. A mode allowed a type only in the sets the list named, and the user wants to save any set that matches well. A combination has no name. Its pieces and its jacket state are its identity, so the app refuses a second combination with the same pieces and the same jacket state.
